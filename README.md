Modern, high-performance personal portfolio website showcasing cross-platform mobile applications, full-stack development, and professional credentials.

---

## 🚀 Features

- **High-Performance Architecture:** Pure CSS transitions, 60–120 FPS hardware-accelerated animations, zero layout reflows.
- **Dynamic Typing Subtitle:** Automated role highlights.
- **Project Showcase:** Live filterable project gallery (Desktop, Mobile & Backend API).
- **Interactive Experience & Education Timeline:** Detailed career and academic progression.
- **Verified Certification:** Embedded credential viewer with full-screen Lightbox Modal and direct PDF download.
- **One-Click Contact:** Instant copy-to-clipboard for Email & Phone with interactive toast notifications.
- **Fully Responsive:** Optimized across mobile, tablet, laptop, and 4K desktop screens.

---

## 🛠️ Tech Stack

- **Frontend:** Semantic HTML5, Modern CSS3 (Glassmorphism), Vanilla JavaScript (ES6+)
- **Icons & Graphics:** FontAwesome 6, Devicon, Official Flutter Vector SVGs
- **Deployment:** GitHub Pages
